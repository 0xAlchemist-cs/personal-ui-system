# 导航模式

状态：`draft`，待真实页面验证与审核。

多模块后台优先侧边导航；文章站优先简洁站点导航和可选正文目录。导航应反映用户任务与实际路由，不能只为填充界面创建菜单项。

- 当前项既有视觉区别，也有适当的语义标记；展开状态与当前路由一致。
- 侧栏折叠后保留可理解的名称或可访问标签，不只剩无说明图标。
- 移动端抽屉有可辨标题、关闭入口和焦点管理；Escape 关闭，关闭后焦点返回触发元素。
- 固定页头不遮挡正文标题或锚点；导航可按内容拥挤情况切换，不强制同一断点。
- 没有目标页面的菜单项不伪装成可点击链接；权限限制与普通禁用说明分开处理。

复用成熟组件的键盘与焦点行为；审核记录说明路由、视口和键盘流程覆盖范围。参考 [设计原则](../../design-system/principles.md)。
