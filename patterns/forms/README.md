# 表单模式

状态：`draft`，待真实页面验证与审核。

按用户任务分组，默认使用清晰的可见标签。字段顺序对应实际输入过程；不要用占位文字替代标签，也不要为很短的表单引入分步向导。

- 必填、格式和帮助说明在提交前可理解；错误与字段关联，保留输入，必要时将焦点移至错误摘要或首个错误。
- 明确校验时机，避免用户刚输入第一个字符就显示完整错误；异步校验与提交结果分开说明。
- 提交期间防重复请求；成功说明保存结果与后续动作；失败保留编辑状态并提供可行恢复路径。
- 禁用有具体原因且不只通过 tooltip 表达。只读与禁用根据是否仍需复制、聚焦和阅读区分。
- 对话框适合范围有限的编辑；多区域、长表单优先独立页或其他合适结构，遵循项目已有模式。
- 取消不得意外保存；确有未保存输入时，按项目约定处理离开页面或关闭行为。

先复用项目表单能力，不新增重复状态或校验引擎。参考 [设计原则](../../design-system/principles.md)。
