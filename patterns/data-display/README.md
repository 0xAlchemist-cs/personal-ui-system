# 数据展示模式

状态：`draft`，待真实页面验证与审核。

先确定比较、检索还是趋势判断是主要任务，再选择表格、列表或图表。统计卡必须有真实指标定义与数据来源，不把演示数字当成产品事实。

- 表格列包含用户完成任务需要的信息；数字与日期采用便于比较的一致格式，单位明确。
- 筛选靠近结果，显示生效条件；区分本地与服务端分页排序，不将当前页排序误称为完整结果排序。
- 筛选与排序变化后一般回到第一页；刷新或编辑使页数变化时修正越界页码，保留合理上下文。
- 区分首次无数据、筛选无结果、权限不足与请求失败，不统一显示“暂无数据”。
- 批量操作说明选择范围，特别是当前页与跨页选择；选中数据失效或权限变化时处理执行失败。
- 手机保留关键字段和操作入口，通过局部滚动或详情补足信息；局部滚动区具有适当名称且可键盘访问。
- 图表提供可理解的摘要或数据表，颜色之外使用文字、标记等区分；悬浮提示不能是唯一数据入口。

优先复用项目已有的表格与查询能力。参考 [设计原则](../../design-system/principles.md)。
