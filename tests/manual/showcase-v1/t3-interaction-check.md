## 发现并修复的问题

1. 连续 Tab 从官方弹窗最后一个控件移向浏览器界面时，官方焦点圈定未阻止短暂越界。补充应用内 Tab 首尾循环，并同时验证正向与反向；保留官方焦点锁、Escape 等能力，不拦截 Ctrl/Alt/Meta 组合键。
2. 弹窗开场回调的姓名自动聚焦可能打断已开始的邮箱编辑。仅当焦点尚未位于编辑表单中时聚焦姓名；保存前核对实际输入，编辑导致结果变化的旅程通过。
3. 抽屉开场焦点先位于外层容器、快速关闭时官方焦点返回存在时序问题。开场后将焦点移到实际导航；由打开状态的 effect 在焦点锁释放后返回记录的入口，Escape 与快速关闭检查均通过。

最初预览服务在沙箱内、Chrome 在外部环境，连接超时；在同一环境重启服务后可访问。另修正了检查脚本误将 Select 搜索输入值视为选中值的断言。上述调试失败不作为最终通过证据，最终结果以关联 JSON 为准。
