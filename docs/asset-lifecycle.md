# 资产生命周期

## 成熟度

| 状态 | 含义 | 使用方式 |
| --- | --- | --- |
| `draft` | 规则或实现尚未通过真实页面验收 | 可以试用，但说明风险，不能宣称已验证 |
| `validated` | 在明确记录的页面、状态和视口中通过基本检查与人工视觉验收 | 作为候选复用资产，保留验收记录和限制 |
| `approved` | 有跨项目复用价值，已经用户或指定维护者审核同意进入公共资产目录 | 按版本发布，记录接口、来源和兼容性 |
| `deprecated` | 有替代方案，处于兼容迁移期 | 保留迁移说明，不静默删除 |

“validated”只适用于记录覆盖的范围；一个页面通过不等于所有组件、设备或主题都已通过。当前初始规则和三套风格都是 `draft`。

## 收录依据

候选资产需说明：解决的问题、已有资产为何不适用、适用技术栈、输入输出或交互边界、真实使用位置、验证证据和维护者。只有单个项目需要的业务组件，先留在该项目。

复用价值来自明确的重复需求和稳定的职责，不以封装层数、截图精致程度或 API 数量评判。导航、表单、数据展示中的新模式经过审核后再晋级为公共模式。

## 变更与兼容性

知识库版本记录在根目录 CHANGELOG。当前 0.1.0 表示起始快照，不承诺跨版本自动兼容。

- 新增可选规则或不影响现有语义的说明：记录新增内容与使用范围。
- 调整颜色、间距、密度、字体或布局默认值：记录受影响页面；实现阶段附前后截图和验收结果。
- 删除或重命名 Token、改变语义、组件接口或 Brief 必填字段：作为破坏性变更评估，列出消费者、替代方案和迁移步骤，经授权后发布。

快照消费者自行评估和采纳更新；修改知识库不会自动覆盖其他项目。未接入消费者清单时，不声称已经评估所有项目的兼容性。
