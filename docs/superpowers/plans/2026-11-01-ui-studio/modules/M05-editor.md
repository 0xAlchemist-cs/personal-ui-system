# M05｜自由拼装、属性编辑与响应式

> **For agentic workers:** Use executing-plans to implement this assigned module. Steps below are future checklist items.

**Goal:** 用户可从喜欢的方案或保留购物车的空画板开始，实际编辑组件、布局和多设备覆盖。
**Architecture:** 遵循共享文档与注册表，具体供应方类型限于适配层。
**Tech Stack:** 使用现有目标应用锁文件；新增依赖须有本模块实际用途。

## 输入与输出接口

供应方适配层只负责选中/拖动/缩放/渲染的事件映射；设计修改必须变成 EditCommand。编辑和预览都从 DesignDoc+registry 读取，不直接改 DOM 样式后丢失数据。

## 实施步骤

- [ ] 1. 交付三栏工作区：左侧页面树/组件插入区，中间画布，右侧属性面板；支持页面选择、设备切换、缩放、撤销重做。
- [ ] 2. 支持 insert/move/duplicate/remove；跨容器及跨页面移动保留节点 props/样式。容器内提供行、列、网格和自由定位模式；拖动不能依赖复制截图。
- [ ] 3. 通用面板支持宽高、padding、gap、radius、字体角色/字号/字重、文字色、背景色；组件专属面板显示其已注册字段，不假称所有组件内部元素都可任意解构。
- [ ] 4. 对自由定位提供 x/y、拖拽和缩放；坐标相对选中容器，可形成有意重叠。保留层级顺序控制，修改可序列化和撤销。
- [ ] 5. 默认桌面操作更新基础 style；平板/手机修改写各自 overrides。每个覆盖可重置；预览不是等比缩小桌面截图。列布局按规则重排，自由节点的裁切/遮挡给出可定位提示，用户可手动修正。
- [ ] 6. 运行预览隔离选中框、拖动层及键盘快捷键；弹窗、输入、Tabs、轮播和动效执行真实逻辑。Esc 退出预览回画布原选中元素。
- [ ] 7. 文字编辑时 Delete/Ctrl+Z 属于输入框而非删除节点；画布 Delete 仅作用选中节点。提供可键盘操作的移动上下/移入页面等替代操作。
- [ ] 8. 改全局风格保留业务内容和结构；具体数值覆盖仍保留并可一键恢复该节点默认样式。预览结束不记住暂态表单输入。
- [ ] 9. 初始自由拼装按分组建立页面和空容器，所选组件在插入区；不是偷偷使用不喜欢的候选。

## 可判定验收与停止条件

- [ ] 同一实际按钮可插入、拖动、改文案/颜色、撤销，再导出 JSON 重载获得同效果。
- [ ] 能自由定位与重叠两个节点，并调层级；手机端能找到裁切提示并单独修正，桌面值不被覆盖。
- [ ] 从某候选创建工作稿后修改，候选原稿深比较不变；从 null 开始也能独立完成页面。
- [ ] 至少测试 Tabs、EditDialog、轮播三种运行交互和一种持续动效；编辑点击不会同时打开对话框。
- [ ] 375/768/1440px 实际宽度下核对布局、焦点和可读性；设计编辑主工作区可优先桌面浏览器，窄屏至少可浏览和预览并明确编辑操作限制。
- [ ] 关闭再打开项目后，位置、组件参数、设备覆盖和层级均可恢复。

## 补充边界

不把“全局任意 CSS/JS 输入”作为自由编辑的捷径；只开放明确可保存和导出的字段。响应式自由区域需要人工微调的限制必须在 UI 可见。
