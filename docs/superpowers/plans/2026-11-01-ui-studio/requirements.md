## 实施建议与可调整范围

下列是本计划给工程实施的明确建议，不冒充额外用户选择：36 项清单见 M02；三套已有预设作为首批风格；项目保存使用 IndexedDB；候选方案不可原地覆盖，编辑时复制为工作稿；预览以桌面 1440、平板 768、手机 375 CSS px 为验收宽度。这些建议如因实际验证无法落地，记录具体差异再调整本文件，不静默改变已确认行为。

## 图库与编辑器的职责

图库提供可搜索的封面、用途、风格、支持行为及“加入购物车”。详情展示同一组件实现的实时预览。编辑器提供页面树、组件插入区、画布、属性面板、撤销重做和设备预览。购物车不是代码依赖安装列表；加入组件不会安装新的 UI 框架。

编辑模式的点击用来选中组件；运行预览的点击交给组件。不能让一个点击同时拖动组件并触发业务操作。组件运行状态如弹窗开关、输入值、排序页码不写入设计历史；只有用户明确修改演示初始属性时才更新设计文档。

## “新设计”的可检验含义

结构差异包括主要区块顺序、页面内主辅区域分配、容器嵌套及列数变化。仅改颜色、随机坐标、卡片圆角或交换两个无主次按钮不算新设计。保持用户已确认的页面划分、功能与风格；不能为了凑三套丢掉组件。

生成规则是有限集合。相同输入与相同 seed 可重现，换一批方案只在未用完的有效组合里取样；不足三套时明确显示数量和限制原因，保留自由拼装入口。不能伪造三个相同页面或承诺无限原创。

## 修改和导出的语义

选中候选时创建工作稿；候选作为初始对比样本保留。默认导出工作稿；若未进入编辑，选中候选也先物化为工作稿。“全部三套”导出每套当前可用版本；与某候选关联的工作稿替换该候选在导出中的版本，并标注“已编辑”，其他两套保持原稿。纯自由拼装项目只有一份工作稿，全部三套选项不适用，不自动凑出两套。

PNG 表达静态时刻，不代表动画录像；参考包另附交互、状态、动效参数和项目 JSON。业务数据均为演示数据，未接入后端不声称提交到真实服务。

## 本轮不包含

账户、跨设备同步、多人协作、云存储、在线 AI、任意 npm 包动态加载、直接发布用户网站、生产后端生成、完整 Figma 矢量工具、视频导出、公共组件包发布。已有知识库与消费者快照仍按原约定维护。
