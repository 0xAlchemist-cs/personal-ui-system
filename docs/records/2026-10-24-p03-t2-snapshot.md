## manifest 与检查契约

消费者 `.personal-ui/manifest.json` 使用本试点自定义的 `schemaVersion: "1.0"`。其 `sourceRepository`、`sourceCommit`、`systemVersion`、`preset`、`presetConfiguration`、`copiedAt` 固定来源与组合；`consumerBaselineCommit` 保留选型基线。`includedFiles` 记录 16 项来源路径、Git Blob、源/目标 SHA-256 与修改标记；`localOverrides` 与五项修改一一对应。`generatedFiles` 记录快照 README，`integrationFiles` 记录四个消费者集成文件。manifest 本身不参与自哈希。

`externalDependencies` 仅声明源模块的 `antd@6.6.7` 类型依赖和 `vitest@5.0.5` 测试依赖，未在消费者安装。Vitest 版本是来源测试环境记录，不替代 T3 的消费者依赖选型和锁文件。

无依赖的 Node 校验器只读消费者文件，检查规范相对路径、越界与符号链接、实际文件清单和哈希、覆盖一致性、本地 Markdown 目标、TS 字面量导入以及完整 Token 别名图；本源 `blob/tree` 历史链接必须钉住来源 SHA。它不联网，不检查 Markdown 标题锚点，不执行 TS 或外部依赖。16 项源对象已在本轮另行与本库固定 Git 提交核对；消费者校验器本身不会拉取上游证明来源。
