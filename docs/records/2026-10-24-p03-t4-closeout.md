## 演进决定与剩余手动步骤

- **继续闭合快照。** 只有一次独立接入，T2 的选择、链接裁剪、EOL 和哈希处理是已发现的手动成本；T3 重装用于验证独立性，不代表多消费者重复分发需求。当前不新增通用复制脚本或 CLI；第二个实际接入或多次升级确认重复步骤后，再评估最小复制辅助。
- **公共包、Registry、自建 MCP：当前 Not needed。** GitHub 公开保存和 MIT 授权已经落实，但尚未指定组件包/Registry 发布目标；Showcase 是来源验证应用，不算第二个独立消费者。本轮没有执行 P04-B1/B2 或发布工程。
- **有价值的候选资产保留原位。** 纯 Resolver、适配器及其契约测试已有复用证据，可继续作为候选来源；尚未经过公共接口、维护责任和兼容性收录审核，不自动移动到公共组件目录或标记 approved。业务页与布局继续留在各自应用，三套风格成熟度不变。

每次接入仍需人工选栈/预设与最小文件集合，检查链接裁剪和局部覆盖，记录来源 Git 对象/哈希，接入该项目的 Provider 与页面样式，生成自己的依赖锁，核对独立性并完成真实页面验收。消费者没有远端，后续更改还需提交并更新其 Git 备份；bundle 用于恢复，不作为运行依赖或安装器。

消费者继续钉住上述来源与最终提交。本轮把 [复用指南](../guides/project-reuse.md#快照升级与回退) 补为唯一长期操作入口：升级前固定当前消费者/manifest，再选完整目标 SHA、评估版本及语义差异，逐项合并局部改写、重算清单，执行干净安装和页面验收后才采纳。失败时回到最后验收提交或在新目录从归档恢复，保留失败证据。**升级/回退流程本轮仅文档化，未实际演练**，不承诺自动升级或跨版本兼容。
