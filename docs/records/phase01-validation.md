## 静态颜色对比

每套预设检查 11 组明确颜色搭配：正文及辅助文字分别位于 canvas / surface / elevated、强调按钮文字位于默认及 hover 背景，以及三类状态文字位于对应背景。全部达到普通文字 4.5:1 目标。

| 预设 | 所检查文字搭配中的最低对比度 |
| --- | --- |
| `minimal-saas` | 4.79:1 |
| `developer-editorial` | 5.71:1 |
| `enterprise-data` | 4.79:1 |

另检查 controlBorder 和 focus 在 canvas / surface 上的对比度至少 3:1。这仅验证指定静态 HEX 搭配，不覆盖透明度、浮层、图表、组件禁用态或最终页面。
