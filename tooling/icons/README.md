# UI system 桌面图标

2026-10-31 按用户要求使用 imagegen 生成专属图标：蓝色圆角底板与三个布局面板，白色与冰青色区分组件区域，无文字以适应小尺寸。

- `ui-system.png`：生成的透明背景原图，随项目保存。
- `ui-system.ico`：由原图转换的 Windows 图标，包含 16、24、32、48、64、128、256px 七档尺寸，保留透明度。

[快捷方式生成脚本](../../tools/create-ui-system-shortcut.ps1) 使用该 ICO。移动仓库后重新运行脚本即可更新本机桌面快捷方式的图标路径；不依赖生成工具的本机缓存。此资产用于当前工作台标识，不改变设计预设与组件成熟度。
