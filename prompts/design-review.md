# Personal UI System — 设计评审提示词

请评审当前页面或明确指定的设计方案。先读取项目 AGENTS.md、实际 UI Brief、所用预设和相关模式；以项目明确约束为准。

输入需要包含目标用户与主要任务、页面或源码位置、现有截图与验证环境（如已有）。缺少真实渲染时可以先做源码或方案评审，但不得把推测写成已观察到的页面问题。

依次判断：

1. 页面主要任务、关键内容和下一步行动是否清晰；有无虚构或无意义的指标与装饰。
2. 标题、正文、辅助说明及操作层级是否一致，留白与对齐是否符合所选预设。
3. 配色、字体、间距、圆角、阴影是否复用语义 Token，是否混入不相关风格。
4. 组件能否复用项目已有实现；额外封装是否解决真实问题；组件职责与数据边界是否清楚。
5. 加载、空数据、错误、成功、禁用状态是否完整且适用，筛选无结果是否与首次无数据区分。
6. 键盘、焦点、输入标签、文字对比和移动端操作是否可用。

输出优先级最高的具体问题：位置或证据、用户影响、最小修复建议。区分必须修复与可选优化；没有证据时标明待验证，不凭喜好要求重构整个页面。不修改文件，除非本次任务已经授权实施修复。

最后说明复用了哪些资产，哪些候选规则需要真实页面验证，以及哪些修改可能影响其他消费者。
