# Personal UI System — 视觉验收提示词

请验收指定页面的实际渲染与典型交互。先读取项目 AGENTS.md、UI Brief、当前预设及验收条件，启动项目已有开发或预览命令。

优先使用目标项目已有浏览器与测试工具。检查桌面和移动布局、主要数据与提交状态、键盘流程和焦点；参考视口为 375、768、1440px，项目指定尺寸优先。

- 观察标题换行、间距节奏、对齐、溢出、文本截断和关键操作可达性。
- 执行 Brief 中的关键行为，检查筛选、排序、分页、编辑或提交的实际结果。
- 记录有业务意义的 loading / empty / error / success / disabled 分支；不适用项给出理由。
- 操作对话框、抽屉和表单，验证标签、焦点进入与返回、Escape 和错误恢复。
- 检查 200% 缩放和减少动态效果设置下的可用性。

若项目已有视觉回归，固定 OS、浏览器版本、字体、视口、数据与时区，等待字体和布局稳定后比较。截图变化先人工判断，不自动更新基线来消除失败。[Playwright 视觉比较说明](https://playwright.dev/docs/test-snapshots)

把证据记录到 [人工验收模板](../tests/visual-review-template.md) 或项目现有报告。说明每项的页面、环境、操作和结果，附可访问的截图或报告位置。没有浏览器、截图或基线时如实标记未执行，不把静态检查当作视觉验收。
