# Blog 页面规格

状态：`draft`，这是设计规格，没有页面源码。默认采用 `developer-editorial`。

## 信息结构

```text
站点导航
├─ 索引：个人介绍 / 文章标题、日期与必要摘要
└─ 文章：标题 / 日期 / 正文 / 可选目录 / 返回索引
```

正文采用受控阅读宽度；标题、链接、引用和代码拥有一致规则。没有真实内容时展示空状态，不虚构作者经历或文章。少量文章不自动引入搜索、标签体系或分页。

## 交互与验收

站点导航、文章与锚点可键盘访问。代码块仅局部滚动；长标题、中文段落和手机目录需实际验收。处理文章不存在，静态页面不为加载效果加入不必要请求。

参考 [博客 Brief](../../briefs/examples/blog.yaml) 与 [导航模式](../../patterns/navigation/README.md)。
