# Dashboard 页面规格

状态：`draft`，这是设计规格，没有页面源码。优先评估 `enterprise-data`；轻量任务工作台可以使用 `minimal-saas`。

## 信息结构

```text
应用导航
└─ 页头：当前位置 / 必要的全局操作
   └─ 主内容
      ├─ 页面标题 / 时间或业务范围 / 主要行动
      ├─ 真实关键指标（有定义和来源时才展示）
      ├─ 主要任务区：趋势、待办或业务列表
      └─ 详情入口与更新时间
```

围绕用户要做的决策选择内容，不默认添加四张统计卡和两张图。多个数据源分别处理加载与失败，避免单个次要请求阻塞整个页面。

## 交互与验收

时间或业务范围变化后明确影响哪些区块。图表提供摘要，列表保持筛选语义。移动端优先保留主要任务，重新排列区块而非等比例缩小。验证真实数据、无数据、局部错误、过期数据和恢复操作。

沿用 [数据展示模式](../../patterns/data-display/README.md)，从 [UI Brief](../../briefs/README.md) 补齐来源、字段和验收条件后再实现。
