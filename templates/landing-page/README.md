# Landing Page 页面规格

状态：`draft`，这是设计规格，没有页面源码。可以从 `minimal-saas` 的语义 Token 起步；需要独立品牌风格时先提出候选变体。

## 信息结构

```text
品牌与简洁导航
├─ 价值主张 / 面向人群 / 主要行动
├─ 真实产品能力与使用场景
├─ 有来源的案例或证据（存在时）
├─ 帮助决策的常见问题
└─ 最终行动与必要链接
```

内容顺序服务用户决策，不机械添加所有区块。不虚构客户 Logo、评价、增长数字、价格或功能。

## 交互与验收

行动按钮有真实目标；表单具备标签、校验和提交反馈，外部跳转目的可理解。手机先保证价值主张与主要行动可见。图片有合适替代文字，动画尊重减少动态效果设置。只有真实提交或请求才需要对应加载与禁用状态。

参考 [设计原则](../../design-system/principles.md) 和 [表单模式](../../patterns/forms/README.md)。
