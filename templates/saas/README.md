# SaaS 页面规格

状态：`draft`，这是设计规格，没有页面源码。默认采用 `minimal-saas`。

## 信息结构

```text
应用外壳（仅多模块时需要侧栏）
└─ 页面标题 / 说明 / 主要行动
   ├─ 资源列表：筛选 / 结果 / 分页 / 详情或有限编辑
   └─ 设置页面：任务分组 / 字段 / 保存反馈
```

资源管理和设置是两类页面，不把所有能力挤入一页。优先映射现有组件，职责名不代表本库已经提供实现。

## 交互与验收

表单说明保存时机与持久化边界；筛选、页码和地址栏状态是否同步由真实需求确定。空数据提供相关行动，筛选无结果提供清除条件，保存失败保留输入。验证手机操作、键盘、对话框焦点与成功反馈。

参考 [管理页 Brief](../../briefs/examples/user-management.yaml)、[表单模式](../../patterns/forms/README.md) 和 [数据展示模式](../../patterns/data-display/README.md)。
