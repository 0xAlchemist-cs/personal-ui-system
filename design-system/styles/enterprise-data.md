# Enterprise Data

状态：`draft` · [Token 数据](enterprise-data.json) · [参考来源](../references.md)

适合运营后台、数据管理、权限配置和复杂表单。密度来自信息组织与空间节制，不来自压缩字体、隐藏标签或塞满操作。

## 颜色与排版

浅色容器与页面底色区分工作区域，蓝色用于主要行动和选中。正文 14px、行高 1.5，页面标题 24px。状态标签始终带文字，数字适合对齐比较时使用等宽数字特性，不把代码字体应用到全部正文。

控件圆角 4px，容器 6px，少用阴影。表格行高和列宽服从实际内容，不为每一列设置统一宽度。

## 布局节奏

最大内容宽度 1440px，桌面页边距 24px，容器内边距 16px，区块间距 24px。默认页头 56px，侧栏 240px；筛选区、结果工具栏、表格与分页保持水平对齐。

桌面控件高度目标 32px，手机主要控件使用 `size.controlTouch`（44px）并检查点击间距。移动表格保留关键列，通过局部滚动或详情访问其余数据，不让操作列消失。

## 组件与交互

Ant Design 项目直接优先官方 Table、Form、Select、Drawer、Modal 等，复杂业务界面再评估 ProComponents；实际 API 由安装版本的官方资料确认。非 React 项目保留布局与交互规则，采用其兼容组件体系。

筛选、排序、分页明确在客户端还是服务端执行。筛选变化通常回到第一页；批量选择说明跨页是否保留。删除和批量修改说明影响范围，执行失败保留上下文并提供恢复路径。

## 避免

避免后台首页默认铺无业务来源的图表、表格内每格放卡片、无标签图标操作堆积、在尚未选择数据时启用批量操作。

## 可复制的风格表达

> 使用 `enterprise-data` 的浅色、蓝色强调、紧凑密度和小圆角。筛选、工具栏与结果对齐，保持表格比较效率和清晰的状态文案。沿用目标项目组件，明确筛选分页、批量选择与错误恢复语义，手机端单独检查操作可达性。
