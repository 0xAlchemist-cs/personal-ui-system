# Developer Editorial

状态：`draft` · [Token 数据](developer-editorial.json) · [参考来源](../references.md)

适合个人主页、技术博客、文章索引与长文。重点是阅读节奏、作者表达和可扫描的目录。深色与薄荷色为本库候选偏好，不是所列参考站点的官方配色。

## 颜色与排版

- `color.canvas` 为深色阅读背景，正文 `color.text`、辅助信息 `color.muted` 保持清晰；不使用纯灰低透明度文字堆叠。
- 薄荷色用于链接与少量行动，链接同时有下划线或其他可辨标记。强调色按钮使用深色 `color.onAccent`。
- 标题使用 `font.heading` 的衬线栈，正文使用本机 UI 字体，代码使用 `font.mono`。
- 正文 16px，行高 1.8；正文最大宽度 `layout.readingMax` 为 68ch。中文排版应结合字形和实际行长微调，不把 ch 当作汉字数。
- 字体仅使用本机可用回退，不承诺不同操作系统渲染一致。缺少衬线中文字体时保留浏览器回退，不擅自下载字体。

## 布局节奏

页面外壳可以使用共享最大宽度；实际文章列受阅读宽度约束。章节间距采用 `space.section`（40px），目录只在足够空间时显示在正文侧边，手机目录折叠并可键盘操作。

文章列表以标题、日期和必要摘要形成节奏，不必逐篇使用卡片。代码块仅在内部横向滚动，避免整个页面溢出。

## 页面与状态

提供可识别的文章标题、发布日期和返回索引入口。无文章、搜索无结果、加载与读取失败有明确文案。长文可以保持服务端或静态渲染，不为展示加载状态强行增加客户端请求。

## 避免

避免终端装饰、无意义打字动画、满屏标签、发光边框，以及只用薄荷色区别正文链接。减少动态效果设置应被尊重。

## 可复制的风格表达

> 使用 `developer-editorial` 的深色阅读背景、薄荷色强调和舒适密度。文章优先，标题与正文形成排版对比，正文采用受控阅读宽度。保留代码可读性、可辨链接、手机目录和键盘导航。
